# 🩸 Qatra Hayat (Drop of Life)

A comprehensive web-based Blood Donation Management System designed to seamlessly connect central blood banks, healthcare facilities, and volunteer donors. The platform automates manual administrative processes, provides real-time tracking of blood inventory, and facilitates rapid responses to medical emergencies.

## ✨ Key Features
* **Donor Management:** Secure registration and comprehensive medical profile management, including blood type and health records.
* **Emergency Alerts:** Instant broadcasting of urgent hospital blood requests to notify eligible donors immediately.
* **Interactive Map:** A built-in geographical map to help donors easily locate the nearest active blood banks and medical centers.
* **Medical Archive:** Detailed personal archives documenting each donor's past transactions and vital signs (such as blood pressure and weight) during previous donations.
* **Admin Dashboard:** A dedicated control panel for system administrators to oversee medical centers, evaluate donor vitals, and explicitly confirm or reject donation requests.

## 🛠️ Tech Stack
* **Frontend:** Interactive user interfaces built with HTML, CSS, and JavaScript.
* **Backend:** Server-side logic and database connections powered by PHP.
* **Database:** Relational database management using MySQL.
* **Environment:** Developed and optimized for local server deployment using XAMPP.
