# 🩸 Qatra Hayat (Drop of Life)

A comprehensive web-based Blood Donation Management System designed to seamlessly connect central blood banks, healthcare facilities, and volunteer donors[cite: 32, 60]. The platform automates manual administrative processes, provides real-time tracking of blood inventory, and facilitates rapid responses to medical emergencies[cite: 28, 60].

## ✨ Key Features
* **Donor Management:** Secure registration and comprehensive medical profile management, including blood type and health records[cite: 33, 70].
* **Emergency Alerts:** Instant broadcasting of urgent hospital blood requests to notify eligible donors immediately[cite: 16, 28, 33].
* **Interactive Map:** A built-in geographical map to help donors easily locate the nearest active blood banks and medical centers[cite: 18, 62].
* **Medical Archive:** Detailed personal archives documenting each donor's past transactions and vital signs (such as blood pressure and weight) during previous donations[cite: 17].
* **Admin Dashboard:** A dedicated control panel for system administrators to oversee medical centers, evaluate donor vitals, and explicitly confirm or reject donation requests[cite: 21, 28, 43].

## 🛠️ Tech Stack
* **Frontend:** Interactive user interfaces built with HTML, CSS, and JavaScript[cite: 12, 64].
* **Backend:** Server-side logic and database connections powered by PHP[cite: 12].
* **Database:** Relational database management using MySQL[cite: 13, 64].
* **Environment:** Developed and optimized for local server deployment using XAMPP[cite: 12, 64].
